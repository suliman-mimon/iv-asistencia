# IV Asistencia

## Problema

Hay asignaturas de la carrera donde un 10% de la nota corresponde a la asistencia a clases. Sin embargo, los profesores no tienen un mecanismo confiable para registrar la asistencia de los alumnos. Además, el profesor debe tener en cuenta los subgrupos de prácticas para la asistencia. También, el estudiante puede cambiar de subgrupo durante las primeras semanas del curso, y se le debe tener en cuenta las asistencias previas al otro subgrupo. Y también, puede haber requisitos de un porcentaje de asistencia a las clases prácticas que si no se cumple no se accede al componente de asistencia, digamos del 50%. Y al final, el profesor necesita saber para cada alumno, qué nota tiene en ese 10% de acuerdo al porcentaje de asistencia total a todas las clases que le corresponden.
